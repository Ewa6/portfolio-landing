Technical Writing Portfolio

Introduction

I’m a technical writer focused on building documentation systems — not just documents.

My work combines structured content, automation, and process to make documentation scalable, maintainable, and useful in real-world environments.

Portfolio Concept

This portfolio is built as a connected system of four areas:

  • Content – clear, structured documentation (Confluence) and blog posts.
  • Process – planning and iteration (Jira).
  • Code – automation and tooling (GitHub).
  • Integration – connecting tools through APIs.

The goal is not just to present writing samples, but to show how documentation works as part of a larger ecosystem.

Current Status

🚧 Work in Progress

I’m currently developing this portfolio through a set of parallel, real-world experiments and artifacts, including:

  • Confluence documentation and structured content for a dedicated use case.
  • Confluence-based artifacts exploring documentation design and organization.
  • API experiments with accompanying documentation.
  • Republishing and refining selected blog content.

This portfolio is being built iteratively, with each component contributing to a broader documentation system.
